Bem-vindo ao meu repositório de evolução académica! Este espaço foi criado para centralizar, organizar e documentar todos os projetos, trabalhos práticos, laboratórios e exercícios desenvolvidos ao longo da minha **Licenciatura em Engenharia Informática e Telecomunicações (LEIT)** na **UTA (Universidade Técnica do Atlântico)**.

O principal objetivo deste repositório é servir como um portfólio técnico que demonstra o meu progresso em lógica de programação, estruturas de dados, programação orientada a objetos, arquitetura de computadores e sistemas de telecomunicações.

| Diretório / Pasta | Unidade Curricular | Principais Focos & Projetos | Estado |
| :--- | :--- | :--- | :--- |
| `📂 Exercicios_C4` | Introdução à Programação | Lógica de programação, matrizes, funções e matemática em C. | Concluído ✅ |
| `📂 Exercicios_C5` | Algoritmos e Estruturas | Desafios avançados de lógica e otimização de código em C. | Concluído ✅ |
| `📂 POO` | Programação Orientada a Objetos | Arquitetura Java, Interfaces Gráficas (GUI) e conexão JDBC. | Concluído ✅ |
